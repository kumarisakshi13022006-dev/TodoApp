# Todo App

A simple and interactive Todo App built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface
- Interactive buttons using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
